# 🎵 Spotify Screen Full

Een luxe fullscreen Spotify-player voor je scherm, monitor of TV.

Bekijk je huidige Spotify-nummer groot in beeld met album artwork, trackinformatie en eenvoudige playback-controls.

## 🚀 Starten

Open de website:

**https://superwelpnl0.github.io/SpotifyScreenFull/**

## 🔗 Spotify koppelen

Om de app te gebruiken heb je een eigen Spotify Developer App nodig.

1. Ga naar **https://developer.spotify.com/dashboard**
2. Maak een nieuwe app aan.
3. Gebruik de instellingen voor je Spotify-app.
4. Koppel je Spotify Client ID aan Spotify Screen Full.
5. Open daarna de website en verbind met Spotify.

Daarna kun je direct aan de slag. 🎧

## ✨ Functies

* 🎵 Huidig Spotify-nummer
* 🖼️ Grote albumcover
* ▶️ Play / Pause
* ⏭️ Volgende nummer
* ⏮️ Vorige nummer
* ⏱️ Playback timeline
* 🌑 Fullscreen donkere interface
* 📺 Geschikt voor grote schermen en TV's
* 🔐 Spotify OAuth-koppeling
